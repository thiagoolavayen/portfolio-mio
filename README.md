# Portfolio web de Thiago Lavayen

Este es el Trabajo Práctico Integrador **Mi Portfolio Web Profesional en GitHub Pages**.

## Contenido

- `index.html`: página principal. Debe mantenerse con este nombre y estar en la raíz.
- `css/style.css`: diseño adaptable a celular y computadora, paleta de colores y animaciones.
- `js/main.js`: JavaScript (tema claro/oscuro, menú móvil, animaciones al desplazarse y copiar enlace).
- `assets/changaya-preview.svg`: imagen **conceptual** creada para presentar ChangaYa; no es una captura real de la aplicación.
- `assets/favicon.svg`: icono del sitio.
- `FICHA_ENTREGA.txt`: texto para completar la ficha del trabajo práctico.

## Cómo abrirlo en tu computadora

1. Descomprimí el archivo ZIP.
2. Abrí `index.html` haciendo doble clic en él.
3. La página ya funciona sin instalar nada. Para probar el botón «Copiar enlace», publicala primero.

## Cómo publicarlo en GitHub Pages

1. Entrá a https://github.com/ e iniciá sesión.
2. Tocá **New repository** y poné un nombre, por ejemplo `portfolio-thiago-lavayen`.
3. Elegí **Public** y creá el repositorio.
4. Entrá a **Add file → Upload files**.
5. Arrastrá **el contenido que está adentro** de la carpeta `Portfolio_Thiago_Lavayen`: `index.html`, `css/`, `js/`, `assets/`, `README.md` y `FICHA_ENTREGA.txt`. No subas solamente el ZIP.
6. Confirmá con **Commit changes**.
7. Entrá a **Settings → Pages**. En **Build and deployment**, elegí **Deploy from a branch**. Seleccioná la rama **main** y la carpeta **/(root)**. Tocá **Save**.
8. Cuando GitHub publique la página, aparecerá un enlace similar a `https://TU-USUARIO.github.io/portfolio-thiago-lavayen/`. Ese ejemplo **no es una URL real** hasta que lo publiques.
9. Probá en el celular y la computadora. Completá la ficha de entrega con la URL del sitio y la del repositorio.

> No hace falta subir un servidor backend: GitHub Pages sirve sitios estáticos. ChangaYa aparece presentado como proyecto académico; **la aplicación no se ejecuta dentro de este portfolio**.

## Personalizar

- Para cambiar la descripción de Thiago o los textos de ChangaYa: editá `index.html`.
- Para cambiar los colores: editá las variables al comienzo de `css/style.css`.
- Si más adelante tenés imágenes reales de ChangaYa, podés reemplazar la maqueta conceptual de `assets/changaya-preview.svg`.
- Una vez que subas el repositorio del código de ChangaYa, podés agregar su URL verdadera en la tarjeta del proyecto; por ahora no inventamos enlaces.
